# Inventory Management System

## About the Project
This is a beginner-level Inventory Management System developed using Python and Tkinter.

## Features
- Add new products
- Update product details
- Delete products
- View inventory records
- Simple graphical user interface

## Technologies Used
- Python
- Tkinter
- PyCharm

## How to Run
1. Install Python.
2. Download the project file.
3. Open it in PyCharm.
4. Run the Python file.
